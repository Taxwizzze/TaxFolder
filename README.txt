TaxFolder — чистильщик папок (финальная версия)

ВОЗМОЖНОСТИ:
- Сканирование папки и статистика по категориям
- Поиск дубликатов по MD5-хешу
- Поиск файлов, не тронутых > 180 дней
- Сортировка файлов по категориям в подпапки
- Переименование по шаблону: YYYY-MM-DD_Категория_номер.ext
- Экспорт отчёта в TXT или CSV
- Настройка категорий через JSON (кнопка «Настройки»)
- Настройка исключений (папки, которые не трогать)
- Переключатель тёмной/светлой темы (сохраняется)

УСТАНОВКА:
1. Python 3.9+ с python.org (галочка "Add to PATH")
2. pip install -r requirements.txt
3. python main.py

ФАЙЛЫ НАСТРОЕК:
- config.json — категории и исключения (создаётся автоматически)
- theme.json — сохранённая тема (создаётся автоматически)

ИСПОЛЬЗОВАНИЕ:
1. «Выбрать» — укажи папку
2. «Сканировать» — статистика
3. Вкладка «Дубликаты» — удалить копии
4. Вкладка «Старые файлы» — переместить в «Архив»
5. Вкладка «Действия» — сортировка/переименование
6. Вкладка «Исключения» — папки, которые не трогать
7. «Экспорт» — сохранить отчёт в TXT/CSV

СБОРКА В EXE:
pip install pyinstaller
python -m PyInstaller --onefile --windowed --icon=icon.ico --name TaxFolder main.py
